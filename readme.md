# 制作アプリのタイトル
かわせ！桃太郎
# 制作アプリの説明（40文字程度）
左・中央・右の3マスから1つを選んで、鬼を避けながら進むゲーム。
# 工夫した点・こだわった点
全部で4ステージ。最後のラスボスのいるステージは背景も変わります。
桃太郎のお話にちなんで、犬、猿、雉の順にステージをクリアするたびに仲間が増え、同時に体力ゲージが増えます。  
鬼に通せんぼされた時にダメージを受けているのが分かるよう、ちょっと震える動きをつけました。
# 次回トライしたこと（または機能）
ステージクリア時に3枚のカードから1枚選んで、当たりだと回復アイテムがもらえる機能。  
ここぞという時にアイテムを使って体力回復する。
# 備考（感想、シェアしたいこと等なんでも）
今回はゲームシステムを考えて文章化してから、Claudeと壁打ちをして仕様書を作り、仕様書をClaude Codeへ渡す、という手順で作成しました。  
ゲーム中で使用する画像は、Claudeのチャットで必要な画像リストをシート形式で出力してもらい、そのリストを元にChatGPTで画像を生成していきました。  
生成した画像をClaudeに指示して、適切な画像サイズに一気に変換できるのも地味に便利でした。
背景画像は地味に苦労しました。  
最初に作った時は真上からの構図ではなく、奥に次のステージが見えるような奥行きのある構図で作っていました。しかし、家族に試遊してもらったところ  
「矢印が何を意味しているのかわかりにくい」  
「プレイ画面では垂直に敵とプレイヤーがいるのに、奥行きのある背景だと自分の居場所と頭で紐づかない」  
真上の絵にすると頭部が見える構図でキャラクターが分かりにくいし  
横向きにしてもいいけど、スマホを縦に持ったままでプレーできるようにしたい  
と考えた上での構図だったので、どう改善するか悩みました。  
でもドラクエのようなRPGは、奥に進む時でも平面の絵を保ったままで絵が成立していることを思い出し、真上からのアングルでキャラクターは正面（もしくは背面）、という構成に変更しました。
