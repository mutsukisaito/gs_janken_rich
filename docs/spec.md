## 0. Claude Code への作業ルール（最初に必ず読むこと）

1. **実装は「9. 実装ステップ」を1つずつ進める。** 1ステップ終わったら必ず止まり、次の3点を日本語で報告してから、ユーザーの「OK」を待つ。
   - 変更・作成したファイル
   - 追加した関数と、それぞれが何をしているか（初学者向けの言葉で）
   - ブラウザで確認する手順
2. ユーザーのOKが出たら、そのステップの内容で git commit する（コミットメッセージは日本語。例：`S4: 当たり判定と体力・歩数の更新`）。
3. **仕様書にない機能は足さない。** 不明な点や、仕様に矛盾がある場合は、実装する前に質問する。
4. コードのルール
   - HTML / CSS / JavaScript ＋ jQuery（CDNで読み込む）。ビルドツール、フレームワーク、npm は使わない。
   - JS は `config.js`（設定データ）と `game.js`（処理）の2ファイルに分ける。
   - 関数は `function 名前() {}` の形で書く（アロー関数・class・async は使わない）。変数は `const` / `let`。
   - **各関数の直前に日本語コメント**で「何をする関数か」「受け取る値」「返す値（あれば）」を書く。処理の途中にも、何をしているかが分かるコメントを入れる。
   - **状態を変える関数**と、**画面に表示する関数（render〜）**を分ける（「8. 関数一覧」参照）。
   - タイマー（setTimeout）は使わない。結果は次のボタン入力まで表示したままにする。アニメーションも使わない（**例外：次の4つだけ、CSS だけで動かしてよい。JavaScript は使わない。OS の「視差効果を減らす」設定がオンのときは動かさない**。①エンディング画面の紙吹雪（上から落ち続ける）②鬼にぶつかったとき、桃太郎と仲間が約0.4秒ブルっと震える ③「？」の鬼が上下にフワフワ動く ④大きいボタン（`.btn-main` と `.btn-sub`：スタート・リトライ・次のステージへ・タイトルへ）を押している間、1.08倍にふわっと大きくなる）。

## 1. ゲーム概要

桃太郎（プレイヤー）が鬼の出る道を進み、仲間（犬・猿・雉）と再会しながら、最後にでかい鬼（ラスボス）を倒すゲーム。
毎ターン「左・中央・右」の3マスから1つを選び、鬼がいるマスを避ける。3択の読み合いという点で、じゃんけんの発展形になっている。

## 2. ルール

### 通常ステージ（ステージ1〜4）
| 項目 | ルール |
|---|---|
| 操作 | [左によける] [前に進む] [右によける] のボタンで、**左・中央・右のマスを直接選ぶ**（今いる位置に関係なく、どのマスでも選べる） |
| 敵の出現 | ボタンを押すたびに、鬼が**必ず1体**、3マスのどれかにランダムで出る（各1/3） |
| 敵の種類 | 青鬼・赤鬼・黄鬼のどれかがランダム（各1/3） |
| 当たり | 選んだマス＝鬼のマス → 体力が減り（青-10／赤-20／黄-30）、**1歩後退** |
| 回避 | 選んだマス≠鬼のマス → **1歩前進** |
| 後退の下限 | 0歩より下がらない（体力は減る） |
| ステージクリア | 10歩に到達したらクリア（ステージ4だけは、10歩でボス戦開始） |
| ゲームオーバー | 体力が0以下 → ゲームオーバー画面 → [リトライ] で**そのステージの0歩目から**。体力は**上限まで回復** |

### ステージクリア時
次の順番で処理する。
1. そのステージに仲間がいれば仲間に加える：**体力上限 ＋ボーナス、現在の体力も ＋ボーナス**
2. クリア回復：現在の体力 ＋20（**上限は超えない**）

| クリアしたステージ | 加わる仲間 | ボーナス | クリア後の体力上限 |
|---|---|---|---|
| 1 | 犬 | +50 | 150 |
| 2 | 猿 | +50 | 200 |
| 3 | 雉 | +100 | 300 |

例：60/100 でステージ1クリア → 110/150 → 回復で 130/150

### ラスボス戦（ステージ4の10歩目で開始）
| 項目 | ルール |
|---|---|
| ボスの体力 | 300 |
| 操作 | 通常ステージと同じ3つのボタン |
| ボスの攻撃 | 毎ターン、3マスのどれかをランダムで攻撃（各1/3） |
| 被弾 | 選んだマス＝攻撃マス → プレイヤーの体力 -30 |
| 回避＋反撃 | 選んだマス≠攻撃マス → ボスの体力 -20 |
| 勝利 | ボスの体力が0以下 → エンディング画面 |
| 敗北 | プレイヤーの体力が0以下 → **ボス戦の最初から**（プレイヤーは上限まで、ボスは300まで回復） |

## 5. 設定データ（config.js）

**ゲームの数値や中身は、すべてここに集める。** ステージや敵を増やしたり変えたりするときは、このファイルだけを書き換えれば済むようにする。

```js

  maxSteps: 10,      // 1ステージをクリアするのに必要な歩数
  startHp: 100,      // ゲーム開始時の体力
  clearHeal: 20,     // ステージクリア時の回復量
  laneNames: ['左', '中央', '右'], // マスの名前（ボタンの順番と同じ）

  // ステージの一覧。ステージを増やすときは、ここに1行足す
  stages: [
    // ally.face … 仲間表示の顔アイコン／ally.back … 桃太郎の後ろをついてくる姿／clearScene … クリア画面の再会シーン
    { name: 'ステージ1',
      ally: { name: '犬', hpBonus: 50,  face: 'img/face_dog.png',      back: 'img/img_ally_dog_back.png' },
      clearScene: 'img/img_scene_clear1.jpg', hasBoss: false },
    { name: 'ステージ2',
      ally: { name: '猿', hpBonus: 50,  face: 'img/face_monkey.png',   back: 'img/img_ally_monkey_back.png' },
      clearScene: 'img/img_scene_clear2.jpg', hasBoss: false },
    { name: 'ステージ3',
      ally: { name: '雉', hpBonus: 100, face: 'img/face_pheasant.png', back: 'img/img_ally_pheasant_back.png' },
      clearScene: 'img/img_scene_clear3.jpg', hasBoss: false },
    { name: 'ステージ4', ally: null,                          hasBoss: true  }
  ],

  // 敵の一覧。敵を増やすときは、ここに1行足す
  enemies: [
    { name: '青鬼', damage: 10, color: '#2b6cff', image: 'img/img_oni_blue.png' },
    { name: '赤鬼', damage: 20, color: '#e53935', image: 'img/img_oni_red.png' },
    { name: '黄鬼', damage: 30, color: '#f9a825', image: 'img/img_oni_yellow.png' }

    sceneStart:    'img/img_scene_start.jpg',    // タイトル画面

    name: 'でかい鬼',
```

## 6. ゲームの状態（state）

**今のゲームの状況は、すべて `state` という1つの変数に入れる。** 画面の表示は、この `state` を見て作る。

```js
// 今のゲームの状況。ボタンが押されるたびに、ここの値が変わる
let state = {
  stageIndex: 0,      // 今のステージ（0から数える。0 = ステージ1）
  step: 0,            // 今の歩数（0〜maxSteps）
  hp: 100,            // 今の体力
  maxHp: 100,         // 体力の上限
  allies: [],         // 仲間になったキャラの名前（例：['犬', '猿']）
  isBossBattle: false,// ボス戦中なら true
  bossHp: 0,          // ボスの今の体力
  lastResult: null    // 直前のターンの結果（表示用）。例：{ lane: 1, enemyLane: 2, enemy: {...}, isHit: true }（ボス戦では isBoss: true も入る）
};
```

## 7. 処理の流れ

### 通常ステージの1ターン（ボタンが押されたとき）
1. 押されたボタンから、選んだマス番号（0, 1, 2）を受け取る
2. 鬼のマスをランダムに決める（0〜2）
3. 鬼の種類をランダムに決める（`CONFIG.enemies` から1つ）
4. 選んだマス と 鬼のマス が同じなら（当たり）
   - 体力を `敵.damage` だけ減らす
   - 歩数を1減らす（ただし0より小さくしない）
5. 違うなら（回避）
   - 歩数を1増やす
6. 結果を `state.lastResult` に入れ、画面を更新する（render）
7. 体力が0以下 → ゲームオーバー画面へ
8. 歩数が `maxSteps` 以上
   - そのステージが `hasBoss: true` → ボス戦を開始
   - そうでなければ → ステージクリア処理 → クリア画面へ

### ボス戦の1ターン
1. 選んだマス番号を受け取る
2. ボスの攻撃マスをランダムに決める（0〜2）
3. 同じなら体力を `boss.attackDamage` だけ減らす。違うならボスの体力を `boss.counterDamage` だけ減らす
4. 結果を `state.lastResult` に入れ、画面を更新する
5. プレイヤーの体力が0以下 → ボス戦をやり直す（プレイヤー体力＝上限、ボス体力＝`boss.hp`）。メッセージ「やられた…もう一度挑戦！」
6. ボスの体力が0以下 → エンディング画面へ

※「通常ターン」と「ボス戦ターン」の判定は、ボタンを押したときに `state.isBossBattle` を見て振り分ける。

### 画面の移り変わり
```
タイトル →[スタート]→ ゲーム（ステージ1）
ゲーム →（10歩）→ クリア →[次のステージへ]→ ゲーム（次のステージ）
ゲーム →（体力0）→ ゲームオーバー →[リトライ]→ ゲーム（同じステージの0歩目）
ゲーム（ステージ4・10歩）→ ボス戦（同じゲーム画面）→（勝利）→ エンディング →[タイトルへ]→ タイトル
どの画面でも [タイトルへ] → タイトル（ゲームは全部リセット）
```

## 8. 関数一覧（game.js）

### 状態を変える関数
| 関数名 | 役割 |
|---|---|
| `resetGame()` | ゲームを最初の状態に戻す（タイトルからスタートするとき） |
| `startStage()` | 今のステージを0歩目から始める（体力は上限まで回復しない。リトライでは別途回復） |
| `handleLaneSelect(lane)` | ボタンが押されたときの入口。ボス戦かどうかで、下の2つに振り分ける |
| `playNormalTurn(lane)` | 通常ステージの1ターンの処理 |
| `playBossTurn(lane)` | ボス戦の1ターンの処理 |
| `clearStage()` | ステージクリアの処理（仲間の追加、回復） |
| `startBossBattle()` | ボス戦を始める（`isBossBattle` を true、`bossHp` を設定） |
| `retryStage()` | リトライ（体力を上限まで回復して `startStage()`） |
| `nextStage()` | 次のステージへ進む（`stageIndex` を1増やして `startStage()`） |

### 補助の関数
| 関数名 | 役割 |
|---|---|
| `getRandomInt(max)` | 0 から max-1 までのランダムな整数を返す |
| `pickRandomEnemy()` | `CONFIG.enemies` から1体をランダムに返す |
| `findAllyByName(name)` | 仲間の名前から、`CONFIG.stages` の仲間データ（顔・後ろ姿の画像など）を探して返す。なければ null |

### 画面に表示する関数（state を読むだけで、state を変えない）
| 関数名 | 役割 |
|---|---|
| `showScreen(screenId)` | 指定した画面だけを表示する |
| `render()` | ゲーム画面全体を更新する（下の関数をまとめて呼ぶ） |
| `renderHeader()` | ステージ名（ボス戦中は「ボス戦」） |
| `renderProgress()` | 進捗バー（ボス戦中はボスの体力バー） |
| `renderLanes()` | 3マスに、鬼の画像とプレイヤー（桃太郎＋仲間の後ろ姿）を表示。ぶつかったマスには `is-hit` クラスを付ける。鬼がまだ出ていないときは、3マスの上側に「？」の鬼を出す |
| `renderBackground()` | プレイエリアの背景画像（通常ステージ／ボス戦で切り替え） |
| `renderSceneImages()` | タイトル・ゲームオーバー・エンディングの画像を設定（起動時に1回） |
| `renderHp()` | 体力ゲージ |
| `renderMessage()` | メッセージと顔アイコン |
| `renderAllies()` | 仲間の顔アイコンの表示 |
| `renderClear()` | クリア画面の再会シーン画像と文章 |
| `renderEnding()` | エンディング画面の仲間の顔アイコン |
